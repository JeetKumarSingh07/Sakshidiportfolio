# Sakshi Sinha — Portfolio

This repository contains a small React + Vite portfolio site for Sakshi Sinha.

Quick start

1. Install dependencies:

```bash
npm install
```

2. Run locally:

```bash
npm run dev
```

3. Build for production:

```bash
npm run build
```

Notes
- Static images are stored in `public/images` and referenced from `/images/...` in the app.
- The dev server runs on a dynamic port (Vite will pick an available port). Use the URL shown in the terminal.
